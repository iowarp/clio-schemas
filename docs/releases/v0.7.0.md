CLIO Schemas 0.7.0 is the stable release of the shared record and A2UI contracts used
by CLIO 0.9.7. The schemas are the same as in 0.7.0b1.

### Live data from named artifacts and streams

A chart, map or table can read a named artifact at its latest version, so a view
follows the artifact as it changes. A new stream artifact keeps its content in
clio-core as typed entries; a view can read its latest entry or a window. (#48)

### Richer message records

Messages can carry the workspace resources attached to them and how each reached
the agent, and references to the files, artifacts, sessions, plans or diffs they
point at. Notices record the answer hook that added them, and a compaction's record
lists the messages it summarized and kept. (#46, #49)
