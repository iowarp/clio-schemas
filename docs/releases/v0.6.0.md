CLIO Schemas 0.6.0 makes the shared record and A2UI contracts from the 0.6.0
previews available as a stable Python package.

### Connect study data to views

A2UI views can read live study sources and use selected records to choose the
files shown in viewers. View-opening and workflow-node actions share explicit
selection keys so a dashboard can retain its intended selection. (#43)

### Give viewers room

Viewers can declare a height, and tables can choose their initial page size.
Chart presets also preserve a dotted column name as one field rather than
interpreting it as a nested path. (#43)

See the [CHANGELOG](https://github.com/iowarp/clio-schemas/blob/v0.6.0/CHANGELOG.md).
